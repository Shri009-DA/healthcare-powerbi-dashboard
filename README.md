## 🏥 Healthcare Provider Dashboard | Power BI

Transforming raw healthcare data into powerful insights with Power BI.  
This project visualizes key financial and operational KPIs for a healthcare center, enabling informed decision-making and better management of patient services.

## 📌 Project Overview

This dashboard was created by replicating and enhancing a healthcare dashboard tutorial using Power BI. It offers deep insights into the billing, medication, treatment, and insurance dynamics of a healthcare system. The visuals are complemented by a custom PowerPoint background for a polished presentation.

---

## 🎯 KPI Tracking Summary

This Power BI dashboard tracks several crucial healthcare financial and operational metrics to provide meaningful insights into provider performance and patient cost analytics.

### 📊 Key Metrics Tracked

| **KPI** | **Description** |
|--------|------------------|
| **Billing Amount (£154K)** | Total billed amount across all services |
| **Average Billing per Visit (£679.65)** | Average cost incurred by each patient visit |
| **Medication Cost (£24.57K)** | Total medication-related expenses |
| **Average Medication Cost (£108.26)** | Average cost per medication case |
| **Treatment Cost (£121K)** | Cumulative cost of treatments administered |
| **Average Treatment Cost (£535.44)** | Average cost per treatment |
| **Insurance Coverage (£103.9K)** | Total insurance-covered amount |
| **Average Insurance Coverage (£462.11)** | Insurance contribution per visit on average |
| **Room Charges (£7K)** | Charges related to inpatient room stays |
| **Average Room Charges (£33.10)** | Average cost per room usage |
| **Out-of-Pocket Expenses (£49.63K)** | Total patient-paid expenses |
| **Average Out-of-Pocket (£219.58)** | Average direct patient payment |

## 📈 Visualizations Included

- **Total Billing by Procedure**  
  (X-Ray, MRI, CT Scan, Blood Test, Ultrasound)

- **Total Billing by Diagnosis and Service Type**  
  (Emergency, Inpatient, Outpatient cases for Hypertension, Appendicitis, Asthma, Migraine, Fracture)

- **Billing by Department**  
  (Cardiology, General Surgery, Pediatrics, Orthopedics, Neurology)

- **Billing Amount by City and State**  
  (Geographic distribution of billing amounts across UK cities)
